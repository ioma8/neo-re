# Applet ID index (0xA120..0xA13F)

| ID | Applet or resource |
| --- | --- |
| `0xA123` | Lifecycle test applet |
| `0xA129` | USB Menu Probe |
| `0xA12A` | USB AW Probe |
| `0xA12B` | USB Init Probe |
| `0xA12C` | USB Fault Probe |
| `0xA12D` | USB Silent Probe |
| `0xA12E` | USB Switch Probe |
| `0xA12F` | USB probe / test fixture |
| `0xA130` | Alpha USB |
| `0xA131` | Forth Mini |
| `0xA132` | BASIC Writer |

See the [SmartApplet ID registry](https://github.com/isotherm/betawise/blob/HEAD/applets/REGISTRY.md) to request an ID block.
